## Executive summary

**Overall verdict: structurally sound, with doc-vs-code drift as the dominant risk theme.** The dependency DAG is acyclic and correct (`protocol ← sim-core ← {server,web}`, `air-sim ← sim-core`); game rules genuinely live in pure-TS `packages/sim-core` + `packages/air-sim` with one scoped browser-test exception; server authority is real (input-only `INPUT`, 20 Hz `tickWorld`, thin `intentRouter`, per-intent validators + rate limits + seq dedup); Windows teardown is compliant (`SIGINT/SIGTERM → server.stop() → terminate()`); and the GL HUD is decomposed and testable (pure formatters, `HudHitTester`, `UiToolkit` margins, zone-based Playwright clicks).

**What needs attention before the next feature push:**

1. **Compile-time styling is aspirational, not implemented** — tokens exist (`packages/ui-tokens/src/tokens.stylex.ts`) but `apps/web` has zero `stylex.*` / `ui-tokens` imports and no Vite plugin; the only CSS is a 17-line global reset. Either wire it (splash/debug/settings first) or amend AGENTS.md to "StyleX for DOM chrome only; WebGL HUD exempt".
2. **47 Fallow suppressions with no approval log** — concentrated in `WebGL2Renderer` (6×), `DeckPass` (3×), lighting/FoW/visibility/audio synths. This is the largest systematic gate-bypass vs. the "no ignores without human" rule. Freeze, adjudicate, and extract helpers.
3. **Client accepts broadcasts without runtime shape checks** — `socketCore.handleMessage` casts `as unknown as XBroadcast` (~15×) with no `isV2Packet`/version guard; unknown types are silently ignored. Add minimal per-channel guards before cache commit.
4. **Fragile seq + delta contracts** — every caller passes placeholder `seq:0` relying on `SocketStore.sendIntent` overwrite; per-socket (not per-user) cursor + `seq=0` reset on reconnect replays first intents; `delta.baseTick` is never verified and only 4 of ~10 tick cursors reset on reconnect. Type `sendIntent` as `Omit<Intent,'seq'>`, scope cursors per-user or add an epoch, verify `baseTick`, reset all cursors.
5. **Two margin dialects + fixed-size header** — canonical `38/0.055` vs combat/vitals `52/0.065` (+7–11 px rhythm break); `HeaderWidget` assumes ≥595 px with absolute chip offsets; vitals/combat/dossier can collide at 480p. Centralize `bottomMargin()`/`uiCharWidth`, make the header right-anchored + ellipsized, add a lower-third yield rule.
6. **Stale Playwright + changeset hygiene** — AGENTS.md names `harbor-scenes.spec.ts` which does not exist (real specs: `ui-gl-scenes`, `chart-course`, `chart-draft`); `.changeset/` is empty despite active work. Rename the doc example (or add a shim) and run `yarn changeset` per affected package.
7. **God-host + dual vessel clocks** — `SimHost.ts:1430` + `daemon.ts:850` own accumulator, 3 clocks, sessions, ships, market/fuel/cargo/nav, persist; legacy `schedule.ts` auto-tour coexists with nav-owned vessels via a "skips nav vessels" comment-guard. Extract `SessionRegistry`/`BroadcastClocks`/`PersistSink`; unify vessel motion or add a double-drive assertion.
8. **Coverage holes where it matters most** — `WebGL2Renderer:1558` + `DeckPass:1216` have no dedicated unit tests (only indirect + screenshots); ~164 test files skip `tsc` (all `exclude: **/*.test.ts`); `ui-tokens` has no test script. Add pure-geometry seams + a `typecheck:tests` step.

**Do not regress:** input-only wire + shared `predictStep` resolver, versioned envelope + per-intent validators, lossy-delta/backpressure + scoped ship/market fan-out, `node:` import discipline, vitest co-location + browser-test quarantine, zone-based GL testing.

### 4. Findings — quant/seq, untyped-JSON, reconnect/ordering, authority

- **Quant:** `q2/q1/q0` non-finite→0 (`quant.ts:6-19`); applied in `makeShipSystems/makeNavState` (`shipSnapshots.ts:129-141,199-208`), snapshot/tele/vitals builders; `changedBy(a,b,eps)` drives VITALS body-string suppression (`daemon.ts:819-824`) and `diffAtmos/mergeAtmos`. Byte-stable + small. TODO: VITALS stringifies full vitals per client per tick — fine at current N, revisit if crew cap grows.
- **Seq/ordering:** client `seq` stamped centrally (`SocketStore.ts:250-254` `{v,...intent,seq}` with `seq+=1`), but callers pass placeholder `seq:0` (`ActionRouter.ts:105,110,207,212,221,230`, `MovementController.ts:247`, `FireController.ts:96`, `SessionControlStore.restart:74`). Works only because the store overwrites. Server `isFreshSeq` strictly `>` (`seq.ts:9-12`); `HELLO` exempt, all else deduped per-**socket** cursor (`validatePipe.ts:84-94`). Reconnect resets client `seq=0` (`SocketStore.connect:222`) with a fresh server cursor, so cross-connection replay is possible (low impact: movement latch + idempotent intents). Ticked broadcasts use strict `isNewerTick` drops (`socketCore.ts:128-241`); DELTA requires `full` when no base (`138-141`).
- **Untyped-JSON:** C→S is fully typed+validated (`validateClientIntent` dispatch `validate.ts:52-93`, never throws in tick). S→C is typed TypeScript but **runtime-unchecked on receipt**: `handleMessage` does `JSON.parse` then `as unknown as XBroadcast` casts (`socketCore.ts:128-259`) with no `isV2Packet`/version guard and no `tryBuild` validator; unknown `type` silently ignored (`311-312`). Strength: never throws, stale-tick guards prevent most corruption. Risk: a malformed/mismatched server (or MITM) can inject `NaN`/missing arrays into render; `emptySnapshot` synthesizes `v:2` base from `delta.baseTick` without checking `baseTick` continuity.
- **Reconnect/ordering gaps:** `shouldResumeAfterClose` honors 4400 (`envelope.ts:18-20`, `SocketStore.ts:208-215`) — evicted tab stays dead. Otherwise blind 2 s retry with full `HELLO+SPAWN_ABOARD` and cache reset (`SocketStore.connect:222-226` clears snapshot/telemetry/vitalsTick/manifestSeen but **not** systems/status/nav/chart/cargo/market ticks) — stale ship/nav could linger one tick until newer tick arrives (guards eventually correct). No `baseTick` continuity check: `applyDelta(prev,delta)` ignores `delta.baseTick !== prev.tick` beyond `isNewerTick`; a dropped full + missed deltas still merges (acceptable: next full every 10th resyncs; backpressure `staleSnapshot` sockets skip deltas until next full — `daemon.ts:599-615`).
- **Authority (no leaks found, two mirrors to watch):** server integrates movement; `INPUT` carries only `moveVec/facing/sprint/sealed`. Observer sockets are read-only (`SimHost.ts:433-440` → `observer-readonly`, counted in `droppedLimited`, `daemon.ts:426-429`). Market/fuel gated by distance/phase/hands (`SimHost.ts:500-542`: 150 px console, `docked` phase, `isCarrying`), hire/captain proximity, beacon caps + 2 s cooldown (`sessions.ts:38-55`). Client prediction is reconcile-only (`reconcilePrediction`), shots expire/confirm (`predictedShots.ts:75-96`), fire refused locally via kernel-identical `fireBlock` mirror (`fireGate.ts`) with server truth. One structural note: web imports `sim-core` for **statics/colliders/prediction constants** (`GameSession.ts:11-16` `buildSoloShipWorld/collidersForFrame/withSnapshotStates`; `predictedShots.ts:11` `FIXED_DT/PROJECTILE_*`; `fireGate.ts:8` `fireBlock`; `renderState.withDockWalkable`) — correct per "zero-DOM sim runs both sides," but statics built once (`GameSession.ts:65`) can drift from the live server world if content changes mid-session; docking walkability is render-side unsealing, movement authority stays server-side.

### Frictions / risks

- **Bottom-stack overlap at small heights:** vitals card is fixed `410×228` at `y=h-228-marginY(52/0.065)` (`VitalsWidget.ts:21-25`), combat card `375×182/242` at `y=h-panelH-marginY` (`combatFormatters.ts:41-52`), hints strip `h=34` at `y=h-marginY-44` (`HintsWidget.ts:46`). At 480p the vitals top (~200px) and combat top (~186-246px) can collide with the crew dossier (`HudRenderer.ts:608-616` `420×175` at `marginY+68`) on narrow windows; `packOpen/chartOpen` yield flags exist in `HudDrawState` (`122-125`) but no equivalent yield between vitals/combat/dossier.
- **Header assumes ≥595px + margins:** `HeaderWidget.ts:48-52` (`w=595`, `x=w-595-marginX` with `marginX=max(72,…)`) plus absolute chip offsets `x=420,515` (`27-46`) and alert text at `panel.x-170/-195` (`154-168`). Below ~800px wide the panel clips left content and alert text can run off-canvas; no `uiEllipsize` on `VSSL:` title or `BCN:` code (`65-84`).
- **Two margin dialects drift:** canonical `38/0.055` vs combat/vitals `52/0.065` means bottom cards sit 7-11px higher than the hints strip’s margin basis — visible rhythm break on 1080p; also `combatPanelGeometry` hard-codes `panelW=375` with no `min(w-2*marginX,…)` clamp unlike `UiScreens.visorPanelFor()` (`125-128`).
- **Settings/audio is three parallel implementations:** GL `layoutSettingsScreen` + terminal `voldn/volup/mute` (`terminalLayout.ts:57-72`) + `AudioPrefs`/`AudioBusManager` + DOM `Soundboard`. Mute/volume labels can disagree (`MUTED` vs `VOL n%` in `buttonLabel()` `62-72` vs `AudioSnapshot` `AudioPrefs.ts:22-25`); no single “audio truth” sync test between GL settings screen and bus volumes.
- **Doc/code drift on Playwright + StyleX:** `AGENTS.md:54` names a spec that doesn’t exist; `CHANGELOG.md:845-860,933-934` describes StyleX modals/tokens that have no import in `apps/web/src`. New contributors will look for `harbor-scenes.spec.ts` and `stylex` usage and find neither.
- **A11y / pointer gaps inherent to canvas HUD:** hit zones are mouse/keyboard-focus only (`SplashMount.ts:101-133`, `HudHitTester.ts:87-90`); hidden callsign `<input aria-label="Callsign">` is the sole screen-reader hook (relied on in `ui-gl-scenes.spec.ts:44-49,96-103`); canvas cursor is set manually (`SplashMount.ts:112`, `ViewportDriver` has no hover cursor); no visible focus ringpainted for `keyModeHolder` beyond `setHovered()`.
- **Performance cliff notes:** `HUD_SCRATCH_FLOATS=1<<20` pre-allocated ×2 (`HudRenderer.ts:133-134,189-194`) is ~8MB upfront (fine) but `vectorData/textData` are unbounded `number[]` flushed per frame; `LightingPass` does per-frame `getUniformLocation` (`LightingPass.ts:230-239`) and `WebGL2Renderer` recomputes visibility polygons per light — ok at current light counts, worth profiling before raising the 6-light cap.
